## 게시판 리스트 페이징 ##
-- 사용자가 페이지를 보내 서버는 해당 페이지에 출력되는 게시글을 계산 --
-- ex) 1페이지 요청 => 최신글을 0번이라 가정 0~9번에 해당하는 게시글을 뷰로 보내줘야 함
-- ex) 2페이지 요청 => 10번~19번에 해당하는 게시글에 뷰로 보내줘야 함

#1 boardController.js getList 수정
    ...
    const getList = async (req, res, next) => {
        const category = req.params.category;
        const page = parseInt(req.query.page) || 1;
==> 사용자는 쿼리스트링으로 페이지를 요청
        const boards = await boardService.getBoardsByCategory(category, page);
==> 서비스에게 사용자가 보낸 페이지 정보를 넘겨 DB에서 해당 페이지에 해당하는 10개의 게시글만 가져오기

#2 boardService.js getBoardsByCategory 수정
    async function getBoardsByCategory(category, page) {
        const limit = 10;//DB에서 가져올 게시글의 개수
        const skip = (page - 1) * limit; // 건너뛸 게시글 수 (예: 2페이지면 10개 건너뜀)
        const totalBoards = await Board.countDocuments({ category: category }); // 카테고리별 전체 게시글 수
        const totalPages = Math.ceil(totalBoards / limit); // 전체 페이지 수 (올림 처리)
==> 전체 페이지 수는 페이징 계산을 위해 필요
(게시글이 10개면 전체 페이지 수는 1)
(게시글이 100개면 전체 페이지 수는 10)
(게시글이 200개면 전체 페이지 수는 20)

        const boards = await Board.find({ category: category })
            .populate('author', 'name') // author 필드를 User 컬렉션에서 name만 가져와 채움
            .sort({ createdAt: -1 })    // 최신순 정렬
            .skip(skip)                 // 앞의 게시글 건너뜀
            .limit(limit);              // 페이지당 개수만큼 가져옴

        // 컨트롤러에서 필요한 페이징 정보를 함께 반환
        return { boards, totalPages, currentPage: page };
    }
==> 전체 페이지 수, 현재 페이지를 컨트롤러 거쳐 뷰로 보내기(페이징 계산 때 필요)

#3 boardController.js 수정

    const { boards, totalPages, currentPage } = await boardService.getBoardsByCategory(category, page);
    res.render('board/list', { boards, category, currentPage, totalPages });
==> 서비스에서 가져온 전체페이지 수와 현재 페이지를 뷰로 보내기

#5 list.ejs 수정

    <!-- 페이징 -->
    <nav aria-label="page" class="mt-4">
        <ul class="pagination justify-content-center">
            <!-- 이전 버튼 -->
            <li class="page-item <%= currentPage === 1 ? 'disabled' : '' %>">
                <a class="page-link" href="/board/list/<%= category %>?page=<%= currentPage - 1 %>">이전</a>
            </li>
==> 이전 버튼 클릭 시 현재 페이지에서 -1 페이지로 이동(2페이지에서 이전버튼 클릭 시 1페이지로 이동)

            <!-- 페이지 번호들 -->
        <% for (let i=1; i <=totalPages; i++) { %>
            <li class="page-item <%= currentPage === i ? 'active' : '' %>">
                <a class="page-link" href="/board/list/<%= category %>?page=<%= i %>">
                    <%= i %>
                </a>
            </li>
        <% } %>

            <!-- 다음 버튼 -->
            <li class="page-item <%= currentPage === totalPages ? 'disabled' : '' %>">
                <a class="page-link"
                    href="/board/list/<%= category %>?page=<%= currentPage + 1 %>">다음</a>
            </li>
==> 다음 버튼 클릭 시 현재 페이지에서 +1 페이지로 이동(2페이지에서 이전버튼 클릭 시 3페이지로 이동)

        </ul>
    </nav>
